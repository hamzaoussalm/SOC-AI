# SOC-AI Intrusion Detection System

## Project Description

Design and development of an intelligent network intrusion detection
system based on Artificial Intelligence, with a real-time security
monitoring dashboard.

## Objectives

- Monitor network traffic in real time
- Detect malicious and anomalous activities
- Detect port scans
- Detect DoS/DDoS attacks
- Detect brute-force attacks
- Analyze network protocols and traffic
- Apply Machine Learning for intrusion detection
- Generate security alerts automatically
- Display security events through a real-time dashboard

## Technologies

- CloudLab
- Linux
- Python
- Machine Learning
- Network monitoring
- Packet analysis
- GitHub
- Real-time dashboard

## Cloud Infrastructure

The project will be deployed and tested using CloudLab.
